# 缠论股票分析系统 · 使用指南

本系统以缠论（日线 + 周线）为核心，结合市场环境和基本面，覆盖沪深 A 股的选股、买卖点分析、持仓管理、模拟盘和回测验证。

> 重要提示：系统输出的是基于规则的分析结果，不构成投资建议。截至当前版本，1000 只股票、约 4 年的回测显示缠论日线买点相对随机入场**没有统计上显著的优势**（详见「策略回测」一节和 [迭代计划](迭代计划.md)）。请把推荐当作候选清单和风控工具，而不是买入指令。

## 一、启动与首次配置

### 1. 启动

```bash
# 后端（首次会自动建库 chan_stock 并执行迁移）
cd backend && uv run uvicorn app.main:app --port 8000

# 前端（另开终端）
cd frontend && npm run dev        # 浏览器打开 http://localhost:5173
```

数据库默认连接本机 MySQL `root/123456`，可在 `.env` 里用 `DB_HOST`、`DB_USER`、`DB_PASSWORD` 修改。

### 2. 授权腾讯自选股

打开「设置 → 账户授权」，点「授权腾讯自选股」，在腾讯页面登录并同意授权，完成后会自动回到设置页。授权后点「测试连接」确认可用。

授权过期时系统会自动续期；续期失败时页面右上角的状态会变成未连接，重新授权即可。

### 3. 首次初始化

在「设置 → 数据同步」点「首次初始化」，依次完成：

| 步骤 | 内容 | 耗时 |
| --- | --- | --- |
| 股票池 | 沪深 A 股、申万一级行业、ST 标签 | 约 25 分钟（受 MCP 限频） |
| 日线回填 | 近 5 年前复权日线，来自腾讯公开接口 | 约 1 小时，可断点续传 |
| 评分与估值 | 全市场腾讯诊股评分、PE/PB/市值 | 约 10 分钟 |

初始化完成后点一次「收盘后流水线（强制运行）」，生成第一份市场环境、推荐和持仓建议。之后每个交易日会自动运行。

### 4. 没有授权时：模拟数据模式

```bash
cd backend && DATA_PROVIDER=mock uv run uvicorn app.main:app --port 8000
```

使用本地合成的 300 只股票，数据写入独立的 `chan_stock_mock` 库，不会影响真实数据；写回 App 自动关闭。页面右上角会显示「模拟数据」。

## 二、每天怎么用

系统在交易日收盘后自动完成数据更新和分析，你只需要在晚上或次日开盘前看结果：

1. **市场总览**：先看市场温度和仓位上限，决定今天整体能用多少仓位。
2. **智能选股**：看主推荐，挑几只感兴趣的点「分析」进入个股页。
3. **个股分析**：确认结构和买点，满意就点「按信号开仓」，系统按风险反推建议数量，确认后在模拟盘下单。
4. **持仓与策略**：看每只持仓的建议（保本、减仓、止损等），确认后执行。
5. **推荐跟踪**：每周看一次历史推荐的实际表现，判断策略是否还有效。

所有会动到账户的操作（下单、执行建议）都会先弹窗让你确认。

## 三、各页面功能

### 市场总览

| 区块 | 说明 |
| --- | --- |
| 市场温度 | 0～100 分：指数缠论状态占 50%，市场宽度（上涨家数、站上均线比例、涨跌停）占 35%，量能占 15%。60 以上为强势、40 以下为弱势 |
| 仓位上限 | 强势 80%、震荡 50%、弱势 20%，开仓时会按这个上限约束总仓位 |
| 市场温度走势 | 最近一段时间的温度变化 |
| 市场宽度 | 涨跌家数、涨跌停、站上 MA20/MA60 的比例 |
| 行业强弱热力图 | 面积为股票数、颜色为涨跌幅 |
| 腾讯市场画像 | 来自腾讯的市场整体画像（可能因限频暂缺） |
| 今日推荐 / 持仓与预警 | 推荐前几名和持仓预警的快捷入口 |

顶部横条是上证、沪深 300、创业板、中证 1000 的实时行情。

### 智能选股

每个交易日收盘后自动扫描全市场，流程如下：

1. **基本面与风险过滤**：硬排除 ST、停牌、市值低于 10 亿、股价低于 1 元、营收低于 3 亿且亏损等；扣分类风险（解禁、减持、业绩预亏、经营现金流为负等）每项扣 8 分。
2. **流动性过滤**：近 20 日日均成交额低于 1 亿、流通市值低于 30 亿的不推荐。
3. **缠论扫描**：找近 10 根日线内的一买、二买、三买，计算止损、目标和盈亏比。
4. **打分**：综合分 = 缠论分 × 50% + 基本面分 × 30% + 行业强度 × 20%，再乘以市场温度系数。排名靠前的候选股会补拉三大报表重新打分。
5. **分池**：

| 池子 | 条件 | 是否写回 App |
| --- | --- | --- |
| 主推荐（最多 50 只） | 信号已确认，且不属于降级组合 | 是 |
| 观察池（最多 30 只） | 信号所在的笔或线段尚未确认；或属于回测显著跑输的组合（默认：大盘上涨期的一买、大盘下跌期的三买） | 否 |

卡片上能看到：
- **信号徽章**：一买 / 二买 / 三买；紫色「段」表示线段级别，「强」表示多指标强背驰，带「?」表示未确认。
- **止损与目标条**：止损价、现价、目标一和目标二的位置，以及盈亏比。
- **分项得分**：缠论、基本面、行业三项。
- **风险标签**：黄色小标签，例如「董监高计划减持」。
- **全部理由**：展开后看每一项加减分的原因。

右上角可以切换历史批次，或点「重新扫描全市场」立即重跑（约 10 分钟，其中补拉财报最多 8 分钟）。

### 个股分析

从选股卡片、搜索框或持仓进入。

- **K 线图**：可切换日线 / 周线，叠加笔、线段、中枢、买卖点、成交量和 MACD。图上带「段」的标记是线段级别信号，MACD 浅色区是背驰段。
- **结构概览**：走势类型、相对中枢的位置、最近一笔的方向、MACD 状态。
- **周线与日线联立**：周线方向和共振分。注意：回测显示周线共振向上时入场反而更差，所以共振默认不参与打分，这里只作参考。
- **开仓参考**：按当前信号算好的止损、目标、1R、建议数量和金额。
- **基本面**：腾讯评分、ROE、增速、负债率、估值分位，以及财务趋势（三大报表）。
- **买卖点列表**：每个信号的级别、价格、力度、止损和目标，以及「背驰指标」：面积、DIF、斜率、量能四项中满足了哪几项（面积必须满足；包括面积在内至少三项满足算强背驰）。

「按信号开仓」会打开开仓计划弹窗，确认后在腾讯模拟盘下限价单，并自动建立持仓计划。

### 持仓与策略

每只持仓对应一个持仓计划，每天收盘后自动评估一次，按下面的顺序检查：

| 规则 | 默认值 | 动作 |
| --- | --- | --- |
| 硬止损 | 跌破成本 8% | 全部卖出（交易时段每 5 分钟检查一次并预警） |
| 结构止损 | 收盘跌破缠论结构位（减去缓冲） | 全部卖出 |
| 跟踪止损 | 浮盈 1R 后止损上移到成本，新的向上笔确认后继续上移 | 第一次跌破减仓，第二次清仓 |
| 环境止损 | 市场转弱、总仓位超出上限 | 按比例减仓 |
| 结构卖点 | 出现一卖、二卖、三卖 | 分批止盈（每次三分之一），三卖清仓 |
| 时间止损 | 10 根日线没有进展 | 减仓一半 |

状态依次为：初始 → 保本 → 跟踪 → 减仓 → 清仓。建议出来后点「执行建议」，确认弹窗里会写明原因，确认后才会下单。已平仓的计划可以在「已平仓」页签里复盘。

开仓数量的算法：单笔最多亏总资产的 1%，所以数量 = 总资产 × 1% ÷（买入价 − 止损价）。单只最多占 20%；止损距离超过 12% 时数量减半。

### 模拟盘

对接腾讯自选股「练习赛组合」（虚拟资金），规则和实盘一致：只能交易沪深 A 股、限价单、100 股整数倍、T+1。

- **账户**：总资产、可用资金、持仓市值、总盈亏。
- **下单**：可以按 1/4、1/2、全仓快速填数量，「取现价」自动填价格。下单前会弹窗确认金额。
- **委托记录**：可以撤单；「同步今日委托 / 同步近 3 月」从腾讯拉最新成交。
- **资金曲线**：每天收盘后自动记录快照，也可以手动「记录快照」。
- **复盘统计**：按开仓信号类型统计已平仓交易的胜率和盈亏。

### 推荐跟踪

检验「过去的推荐后来表现如何」，是判断策略是否有效的最直接依据。

- **统计口径**：推荐次日开盘价买入（一字涨停视为买不进、不计入），统计之后 5、10、20 个交易日的收益，以及相对沪深 300、中证 1000 的超额。
- **KPI**：平均收益、平均超额、跑赢比例、Rank IC（推荐分和后续收益的相关性；持续大于 0 才说明打分有区分度）。
- **累计超额曲线**：每批主推荐 5 日平均超额的累加。
- **先到目标还是先止损**：每条推荐先触及目标一还是先触及止损。
- **分组表现**：按信号类型、信号级别、市场温度、主推荐 / 观察池分组。
- **推荐批次**：点任意一批查看每只股票的后续表现。

每天收盘后自动更新最近 60 天的推荐。

### 策略回测

逐根 K 线向前推进，每一步只用当时可见的数据重新计算缠论结构，避免笔和线段「重画」带来的未来函数。

**参数**

| 参数 | 建议 |
| --- | --- |
| 样本数量 | 至少 500 只；100 只以下的结果置信区间很宽，基本没有参考价值 |
| 回看 K 线数 | 950（约 4 年，需要另加 250 根预热） |
| 入场时机 | 笔确认后（与实盘推荐一致） |
| 切分日期 | 留空则前 70% 为样本内、后 30% 为样本外 |
| 滑点 | 默认单边 0.1% |
| 随机对照组 | 建议开启 |

1000 只股票的回测约 2.5 分钟（多进程并行）。

**怎么读结果**

1. **先看「相对同期同市场状态随机组的优势」**：随机组在同一批股票、同一时段随机入场，止损幅度和出场规则都相同，并按信号所在的年份和市场状态加权。95% 置信区间不跨过 0，才能说买点有稳定优势。
2. **再看样本内 → 样本外**：样本外明显变差说明可能过拟合。
3. **信号诊断**：按信号类型、市场状态、信号 × 市场状态、年份、周线共振、背驰强度、信号级别拆开，每组都和同市场状态的随机组比较，并标注「显著跑赢 / 显著跑输 / 不显著」。
4. **逐年滚动检验**：每年只用之前年份的数据挑出跑赢随机组的组合，在当年检验。只有这里也显著为正，回测里找到的规律才算可用。
5. **幸存者偏差**：股票池是当前在市的股票，已退市股票的历史拿不到，结果偏乐观，尤其会高估一买。

**出场规则实验**：左侧「运行实验」会在同一批 1000 只股票上比较 5 组出场规则（基线、取消盈亏比过滤、目标一封顶 2R，以及它们的组合），结果显示在右侧对比表里，点任意一行查看详情。

「建议信号权重」只用样本内交易计算，可以一键保存为新的策略配置。

所有任务都在北京时间运行，运行前会先判断是否为交易日、是否已授权。

| 时间 | 任务 |
| --- | --- |
| 交易日 9:00～15:00 每分钟 | 有待成交委托时同步模拟盘成交 |
| 交易日 9:00～14:55 每 5 分钟 | 用实时价检查硬止损，触发时记录预警 |
| 交易日 15:10 | 同步风险标签与风险事件，并保存当天的风险标签快照 |

| 财报季（4/8/10 月末、5/9/11 月初）18:00 | 评分估值 + 候选股、持仓、自选股的三大报表 |

## 五、写回腾讯自选股 App

开启「设置 → 写回 App」后，每天收盘后的流水线会：

- 把主推荐写入「缠论推荐」自选分组。股票不再被推荐时：
  - 加入推荐分组之前就已经在你自选里的，保留不动；
  - 也在你自建的其他分组里的，只从「缠论推荐」移出；
  - 其余是系统加的，移到 App 的「待删除」分组（可以在 App 里恢复）。
  - 「全部」「沪深」等是腾讯按市场自动归类的系统分组，所有 A 股自选都会出现在里面，不算你的分组。
- 把持仓的止损价和目标价写成股价提醒。写入前先保存你原来的提醒，平仓后恢复。

每次写回的明细（加入、移出、保留）都记在「设置 → 写回 App」的日志里。关闭开关后立即停止写回。

## 六、系统通知

需要你知道的事情会记在「设置 → 系统通知」里，顶栏的铃铛会显示未读数量。目前只在系统内查看，不推送到微信或邮件。

| 通知 | 什么时候出现 |
| --- | --- |
| 任务失败 / 任务被中断 | 任何任务运行失败，或服务重启时任务还没跑完 |
| 流水线部分步骤失败 | 模拟盘对账、推荐跟踪、写回 App 中有步骤出错 |
| 流水线没有成功运行 | 交易日 17:30 仍没有当天成功的流水线；或后端停机期间漏跑，下次启动时补发 |
| 日线没有更新到今天 | 交易日 16:30 最新日线仍不是当天 |
| 快照缺失 | 当天的股票状态、风险标签、估值或评分快照没有写入 |
| 授权失效 | 腾讯授权续期失败 |
| 盘中触发止损 | 交易时段持仓跌破硬止损 |
| 股票池刷新不完整 | 有行业拉取失败（这次刷新只新增、不下线任何股票） |

同一事件同一天只记一次。

## 七、常见问题

**任务很久没有动静，是不是卡住了？**
多半是 MCP 在限频。腾讯的行情和财报类工具每个每分钟只允许 3～5 次调用，系统遇到「服务限频」会自动冷却重试。补拉财报设了 8 分钟上限，超时的候选股改用腾讯评分打分，不影响推荐生成。一次运行被限频太多时，财报接口会进入 30 分钟的配额冷却，冷却期内的运行直接跳过补拉。可以在「设置 → MCP 与限流」看各工具今天的调用次数、限频次数和冷却状态。

**同一天能重跑收盘后流水线吗？**
可以，但会再次消耗 MCP 配额并重新写回 App，所以当天已成功运行过时会先弹窗确认。

**推荐里为什么没有三买（或一买）？**
默认规则会把大盘下跌期的三买、大盘上涨期的一买降级到观察池（回测显示这两类显著跑输随机入场）。大盘状态按中证 1000 相对 60 日均线划分。可以在「设置 → 策略参数 → 按大盘状态降级的信号」调整。

**为什么流动性不足被过滤掉这么多？**
约 40% 的沪深股票近 20 日日均成交额低于 1 亿。这类股票容易出现冲击成本高、被操纵的情况，门槛可在设置里调整。

**「经营现金流为负」的标签为什么这么多？**
这个标签来自腾讯，覆盖了约 44% 的股票，大概率是按单季度口径判断的，区分度有限。它只扣分、不排除，后续版本会重新校准（见迭代计划）。

**北交所的股票在哪？**
