# 多策略分析设计（点金术接入）

## 一、目标

系统从「只有缠论」改为可以同时运行多种策略，每种策略各自有筛选、个股视角、回测检验和持仓跟踪。第一个新增的策略是**点金术**（知乎「奥特之父」提出，在此基础上改良）。

所有策略遵守同一套口径：信号次日开盘价 + 滑点入场，一字涨停买不进、一字跌停卖不出；同时看超额收益、样本外表现和随机对照组；页面显示各自的回测结论和幸存者偏差提示。

## 二、点金术规则

| 类别 | 原版（奥特之父） | 改良版（本系统默认） |
| --- | --- | --- |
| 市盈率 | PE（TTM）< 20 | 同左 |
| 股息率 | > 3% | > 4% |
| 市值 | > 50 亿 | 同左 |
| ROE | 无 | 市值 < 500 亿：近三年 ROE 都 > 15%；市值 ≥ 500 亿：近三年 ROE 都 > 10% |
| 买入 | 收盘价 < MA120 × 88% | 同左 |
| 卖出 | 收盘价 > MA120 × 112% | 同左 |

两个版本都实现，回测时并排比较，用来检验「股息率提到 4% + 加 ROE」是否真的有改善。

## 三、数据现状与补齐

调研结论：点金术需要的历史数据目前**都没有**，必须先补数据，否则回测会有未来函数。

| 数据 | 现状 | 补齐方式 |
| --- | --- | --- |
| 日线价格 | 只有**减法**前复权（例：招商银行 2021-06-01 原价 57.70，前复权 47.20，整体差一个常数），高股息股的均线比例和收益都会失真 | 另拉不复权日线；按每次除权前后的价差算**乘法复权因子**，均线和收益都用乘法复权价（含分红再投入，即全收益） |
| 分红 | 没有 | 从不复权价与前复权价的差值在除权日的跳变得到每股分红；同时用财报的 DividendTTM 交叉核对 |
| 股息率 | 快照表有列但从未写入 | 实时：腾讯行情第 64 个字段（已核对招行 4.95%、神华 4.02%、格力 7.81%）；历史：近 12 个月每股分红 ÷ 当日不复权价 |
| PE | 只有 2026-09-24 一天的快照 | 历史：当日不复权价 ÷ 当时已公告的 EPS（TTM） |
| 市值 | 同上 | 历史：当日不复权价 × 当时已公告的总股本 |
| ROE | 只缓存了 139 只候选股、8 个季度的 ROE（TTM），没有公告日 | MCP `data_finance` 拉 12 个季度以上，保存年报 ROE、EPS（TTM）、分红、总股本和**公告日**；回测只使用公告日之后的数据 |

拉取范围（控制 MCP 限频）：先用腾讯数据算出过去 5 年股息率曾经超过 3% 的股票（预计约 1000 只），只给这些股票拉财报。股息率从未超过 3% 的股票在任何一天都不可能入选，排除它们不会引入偏差。按每批 5 只估算约 200 次调用、1 小时左右，支持断点续传；之后每个财报季只增量更新。

（实测后调整了做法，见第九节。）

## 四、多策略框架

```
backend/app/strategies/
  base.py      策略接口：名称、说明、筛选条件、个股判定、历史信号、回测口径
  chan.py      缠论（包装现有逻辑，不改行为）
  dianjin.py   点金术（原版 + 改良版两个参数集）
```

每个策略实现三件事：

1. **个股判定** `evaluate(code, date)`：逐条列出筛选条件是否通过（带实际数值）、当前所处区域（买入区 / 持有区 / 卖出区 / 中间）、距买入线和卖出线的比例。
2. **每日筛选** `screen(date)`：全市场跑一遍个股判定，结果写入 `strategy_signal_daily`（策略、代码、日期、区域、各项数值）。
3. **历史信号** `signals(series)`：只用当时可见的数据给出每天的买卖信号，供回测使用。

表结构调整：

- 新增 `strategy_signal_daily`、`fundamental_history`（按报告期保存 ROE、EPS、分红、股本、公告日）、不复权价与复权因子。
- 持仓、模拟盘订单、跟踪、回测交易加 `strategy` 字段，历史数据默认记为 `chan`。
- 持仓的止损改为可空：点金术原版没有止损，按卖出线出场；按固定比例定仓位（默认每只 1/N）。

## 五、回测设计

缠论回测按单笔 R 倍数衡量，点金术是低频、持有期长的均值回归策略，需要组合层面的回测：

- **组合模拟**：同时最多持有 N 只（默认 10），等权；每天先处理卖出，再按买入信号排队买入（多只同时触发时按偏离 MA120 最深的先买）；空仓资金计货币基金收益（年化 1.5%）。
- **基准**：中证红利（同风格，最公平）、中证 1000（系统统一口径）、沪深 300。
- **随机对照**：在同一天满足筛选条件的股票里随机买入，持有期按真实交易的持有期分布抽样，重复 200 次，看真实策略排在随机组的什么分位。
- **参数稳健性**：买入线 80%～92%、卖出线 108%～120% 做网格，画成热力图。如果只有 88% / 112% 附近有效，说明是过拟合。
- **版本对比**：原版、改良版、只加 ROE、只提股息率，四组并排。
- **样本外**：前 70% 时间为样本内、后 30% 为样本外；另做逐年表现。
- **结果指标**：年化收益、最大回撤、夏普、胜率、平均持有天数、交易次数、相对各基准的超额、随机对照分位。

## 六、界面

- 导航新增「策略」页：顶部切换策略（缠论 / 点金术原版 / 点金术改良版），每个策略显示
  - 规则说明和回测结论（未检验前显示「尚未检验」）；
  - 今日筛选结果：通过全部条件的股票，按区域分组（买入区 / 接近买入线 / 持有区 / 卖出区），列出 PE、股息率、近三年 ROE、市值、MA120、偏离比例；
  - 未通过的原因统计（例如「ROE 不达标 87 只」）。
- 个股页新增「多策略视角」卡片：每个策略对这只股票的判定和条件清单。
- 持仓页按策略分组，点金术持仓显示距卖出线的比例。
- 「推荐」页保持缠论综合分；点金术只在「策略」页展示，不参与缠论推荐排名。

## 七、分三次交付

1. **数据**：不复权日线与乘法复权因子、分红与股息率历史、财报历史（带公告日）、实时股息率写入快照；数据检查页面显示覆盖率。
2. **框架与实时分析**：策略接口、点金术每日筛选、「策略」页、个股页多策略视角、持仓按策略区分。
3. **回测检验**：组合回测、随机对照、参数热力图、版本对比，结论写入研究报告并显示在策略页。

## 八、已确认的规则（2026-09-28）

1. 近三年 ROE：**每一年**的年报加权 ROE 都要达标。
2. 持有期间不再满足筛选条件：继续持有，直到涨破卖出线（「立即卖出」作为回测对比项）。
3. 不补仓，每只只买一次（补仓作为回测对比项）。
4. 默认不加止损（「跌破买入价 20% 止损」作为回测对比项）。
5. 先做多策略，再做 v0.6 第二次交付。

## 九、第一次交付：数据（实测后的做法）

实测结论：

- 腾讯 K 线的不复权价和除权日分红明细（如「10派19.72元」「10送3转4派2元」）可以回溯到 2010 年以前。
- `data_finance` 支持按报告期起止拉取，一次调用返回招商银行 2018 年以来 31 期利润表，每期带加权 ROE、EPS（TTM）、近 12 个月归母净利润和**公告日**；一批 5 只。
- `tool_filter` 支持历史日期（字段 `PE_TTM`、`DividendRatioTTM`、`TotalMV`），但只能回溯到 2018 年左右，部分日期报错，只用来**核对**自算结果。

因此以自算为主：

| 指标 | 计算方法（只用当天已知的数据） |
| --- | --- |
| 复权价 | 不复权价 × 乘法复权因子；因子由每次除权的「送、转、派」算出，最新一天等于原价 |
| 股息率 | 除权日在过去 12 个月内的每股现金分红（按之后的送转折算）÷ 当天不复权收盘价；招商银行按此算出 2.016 ÷ 40.72 = 4.95%，与腾讯一致 |
| PE（TTM） | 当天不复权收盘价 ÷ 最近一期已公告的 EPS（TTM） |
| 市值 | 当天不复权收盘价 × 总股本（近 12 个月归母净利润 ÷ EPS（TTM）） |
| 近三年 ROE | 已公告的最近三份年报的加权 ROE |

数据范围：先给全部沪深股票拉 2014 年以来的不复权日线和分红，只保留历史上股息率曾经达到 3% 的股票（价值池）的日线；再只给价值池拉 2011 年以来的财报。回测期因此可以覆盖 2015～2026 年。

每日更新：收盘后刷新价值池近 20 天的不复权日线（顺带发现新的除权）；当天股息率达到 3% 的新股票自动补进价值池；财报超过 30 天未更新的分批刷新。

## 实施记录

### 第一次交付：数据（2026-09-28）

- 新表：`kline_daily_raw`（价值池不复权日线）、`dividend_event`（全部股票的分红送转，2014 年起）、`finance_history`（价值池利润表指标与公告日，2011 年起）、`filter_snapshot`（腾讯条件选股历史结果，只用于核对）。
- `analysis/value.py` 统一计算股息率、PE、市值、近三年 ROE、MA120；实测与腾讯行情对比：招商银行、格力电器完全一致，中国神华股息率口径略有差异。
- 数据源只用腾讯 MCP 与腾讯公开接口；`data_finance` 限频最紧，补齐时被限频原地等待重试。
- 审查后追加：日线统一为等比前复权（`services/price_adjust.py` 按分红送转把腾讯前复权还原成原价再按比例复权，配股拟合等效系数）；校验 1054 只价值池股票，84% 每天偏差 < 0.1%，配股股票拟合后偏差从 5%～16% 降到 0.1% 左右。

### 第二次交付：框架与实时分析（2026-09-28）

- `app/strategies/`：策略接口与点金术（`dianjin_v1` 原版、`dianjin_v2` 改良版），判定函数实盘与回测共用。
- `strategy_signal_daily`：每天对价值池逐只判定，记录是否通过、区域、各项数值；`value_daily` 完成后自动扫描，也可在设置页手动运行。
- 前端：新增「策略」页（规则、区域统计、未通过原因、明细表）；个股页新增「多策略视角」。
- 暂未做：持仓按策略区分（放到第三次交付，和回测一起）。
